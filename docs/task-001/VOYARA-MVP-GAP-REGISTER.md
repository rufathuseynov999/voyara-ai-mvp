## Register conventions

- **Launch criticality:** `BLOCKER` prevents a trustworthy launch; `REQUIRED` must be closed before Production but does not block the next foundation task; `DEFERRED` is deliberately outside the first vertical slices.
- **Complexity:** `XS`, `S`, `M`, `L`, `XL` are relative implementation complexity only. They are not time or cost estimates.
- **Founder decision:** `YES` appears only where the current approved baseline does not supply the necessary commercial/public decision.

## Reading the matrix

- **Route** records what exists now. All eight screens are DOM states on `/`; none is an addressable application route.
- **Real** means the stated browser interaction executes. **Simulated** means the interface only renders an example or caption.
- **Responsive** records source evidence only. Fifteen media queries show responsive intent, but a real-browser viewport run could not be completed in the audit environment.
- **Security** never treats hidden DOM state as access control: all eight screens and all fixture data are delivered to every visitor.

## Cross-screen treatment decision

The eight-screen information architecture is retained. The implementation treatment is not a generic redesign: extract the accepted visual tokens and interaction patterns into protected, addressable routes, then enable each action only when its corresponding server-authoritative vertical slice and negative tests exist.

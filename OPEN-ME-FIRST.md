## Open and run the source

1. Extract the ZIP completely.
2. Open the extracted `VOYARA-AI-MVP-COMPLETE-TASKS-001-012` folder in a code editor.
3. Use Node.js 20 or newer.
4. Run `npm install`.
5. Run `npm test` to execute the local test suite.
6. Run `npm run build` to create the Production application build.
7. Run `npm run dev` to start the local application.

The application can build and run without Production credentials by using explicitly bounded local fallback data. Production activation requires the real environment values and every mandatory gate in `docs/task-012/VOYARA-PRODUCTION-LAUNCH-CHECKLIST.md`.

Do not place real Production secrets in source files. Do not use Production personal data in local fixtures.
